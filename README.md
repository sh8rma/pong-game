# Pong Game

A classic Pong game built with HTML, CSS, and JavaScript.

## Features

- 🎮 **Player vs Computer Gameplay** - Control the left (green) paddle against an AI opponent
- 🖱️ **Dual Control Options** - Use your mouse or arrow keys (↑/↓) to move your paddle
- 🎯 **Collision Detection** - Accurate collision physics for paddles and walls
- 📊 **Live Scoreboard** - Real-time score tracking for both players
- ⚡ **Ball Physics** - Dynamic ball movement with spin based on paddle contact
- 🎨 **Modern UI** - Beautiful gradient background with glass-morphism design

## How to Play

1. Open `index.html` in your web browser
2. **Move your paddle** using:
   - **Mouse**: Move your mouse up and down (the paddle will follow)
   - **Arrow Keys**: Press ↑ (up) or ↓ (down)
3. **Score points** by making the ball pass your opponent's paddle
4. The computer AI will try to block your shots

## Game Controls

| Control | Action |
|---------|--------|
| 🖱️ Mouse Movement | Move paddle up/down |
| ⬆️ Arrow Up | Move paddle up |
| ⬇️ Arrow Down | Move paddle down |

## Files

- `index.html` - Main HTML structure
- `styles.css` - Game styling and layout
- `script.js` - Game logic and physics

## Game Rules

- The ball bounces off top and bottom walls
- Players score when the opponent's paddle misses the ball
- The ball gains spin based on where it hits the paddle
- The computer opponent uses AI to track and hit the ball
- Game continues indefinitely

Enjoy the game! 🎮
